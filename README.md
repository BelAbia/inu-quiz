# 🌸 Which InuYasha Character Are You?

A personality quiz inspired by the anime *InuYasha*. Answer a series of questions about your personality and discover which character best matches your choices!
<img width="1916" height="986" alt="image" src="https://github.com/user-attachments/assets/c0eb0433-cb58-4441-9e9f-cb66e78e0b2f" />


## ✨ Features

- Interactive personality quiz with six questions.
- Dynamic question and answer rendering.
- Score-based character selection.
- Personalized results with character images and descriptions.
- Restart functionality to play again.
- Sakura-inspired visual design with animated falling petals.

## 🛠️ Technologies

- **HTML5** — page structure and semantic markup.
- **CSS3** — styling, animations, and responsive layout.
- **JavaScript (ES6+)** — quiz logic, event handling, score calculation, and DOM manipulation.
- **JSON** — external storage for questions, answers, and character data.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/BelAbia/inu-quiz.git
   ```

2. Open the project folder in Visual Studio Code.

3. Install the **Live Server** extension.

4. Right-click `index.html` and select **Open with Live Server**.

5. Click **Start Your Journey** and discover your character!
